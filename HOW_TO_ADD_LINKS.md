# How to Update Survey Links

Edit `index.html` — find the `<nav class="links">` section.
Each link block looks like:

```html
<a href="https://feedbackally.walmart.com/survey/YOUR_ID/" class="link-button" ...>
    <span class="link-icon">📋</span>
    <span class="link-content">
        <span class="link-title">Survey Title</span>
        <span class="link-desc">Short description</span>
    </span>
    <span class="link-arrow">›</span>
</a>
```

After editing just commit — GitHub Pages auto-deploys in ~30 seconds.
